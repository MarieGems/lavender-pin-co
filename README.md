# Lavender Pin Co.

Landing pages for Lavender Pin Co's Pinterest strategy services.

## Pages

**`index.html`** — Pinterest SEO Audit ($197 one-time offer)
- Single self-contained HTML file, no build step
- Hero, how-it-works, benefits, objection-killer, FAQ, final CTA
- Secondary lead-magnet opt-in ("5 Pinterest SEO Mistakes Costing You Traffic") embedded via a live Flodesk form
- Fonts: Poppins / Playfair Display / Inter via Google Fonts
- No external JS libraries besides the Flodesk embed script; fully visible with JavaScript disabled

## Local preview

Open `index.html` directly in a browser — no server or build tools required.

## Deploy

Push to `main` and enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to serve at `https://mariegems.github.io/lavender-pin-co/`.

## Brand

Colors, type, and component rules live in `DESIGN.md` in the main myBusiness project, under the "Lavender Pin Co" section — background `#F3EEF9` is required, not optional.
