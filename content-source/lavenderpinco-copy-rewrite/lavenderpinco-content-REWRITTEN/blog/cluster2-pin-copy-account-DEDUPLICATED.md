# Second Duplicate Cluster (from posts-04) — Rewrite
6 more posts shared the same template problem as the first cluster — same intro, same 5 mistakes, same FAQ, differing only by which 5-step list they used (which itself repeats across 3 of the 6). Same fix approach: distinct angle per post.

### 1. How to Write SEO-Friendly Pinterest Pin Titles (KEEP as the pillar post for this pair)
**New hook:** "A Pin title has about half a second to do two jobs at once — tell Pinterest what it's about, and tell a human why they'd care. Most titles only manage one."
*Role: covers titles specifically. Keep the 5-step approach as-is — it's genuinely title-specific (lead with benefit, keyword near the start, differentiate, match the destination, clarity over keywords).*

### 2. How to Write Pinterest Descriptions That Get Found → Differentiate from titles specifically
**New angle:** Titles are the headline; descriptions are where you actually get to explain — this post should own that distinction instead of repeating the same 5 steps.
**New hook:** "If your title is the hook, your description is where you actually get to explain the catch — most small businesses either skip it or stuff it with the same keyword five times."
**New structure (unique to descriptions):**
- Open with the same core phrase used in the title, restated naturally rather than copy-pasted.
- Add context the title didn't have room for — who it's for, what's included, what problem it solves.
- Use full, natural sentences, not a keyword list — Pinterest and readers both respond better to real language.
- Close with a soft next step when relevant ("Save this for your next..." / "Perfect for...").

### 3. Pinterest Profile SEO: What to Optimize (KEEP as the pillar post for the account-setup trio)
**New hook:** "Your profile is the first thing Pinterest reads to decide what you're about — before it ever looks at a single Pin."
*Role: covers the profile specifically (name, bio). Keep close to original.*

### 4. Pinterest Board SEO: Titles, Descriptions, and Organization → Differentiate specifically to boards
**New angle:** Should own board strategy specifically — not repeat the profile-setup steps.
**New hook:** "'Sparkle & Shine' and 'Board 3' have the same SEO value: none. Here's how to actually structure boards so they work for you."
**New structure (board-specific, distinct from profile post and from the checklist post below):**
- Name boards with the actual phrase a customer would search, not a cute label.
- Write a board description the same way — plain, keyword-first, one or two sentences.
- Group boards around real topics in your business, not vague themes — narrow enough to be useful to Pinterest, broad enough to hold ongoing content.
- Archive or consolidate old boards that no longer reflect the business, rather than leaving them to dilute the account's focus.

### 5. Pinterest SEO Mistakes That May Be Limiting Your Reach → Reframe as a self-diagnostic
**New angle:** Distinct from the other posts by being framed as "check yourself against this list," not another how-to.
**New hook:** "If your Pinterest account has been active for months with flat impressions, one of these is very likely the reason."
*Role: keep as the "troubleshooting/mistakes" post — this pairs naturally with the audit-focused post from cluster 1 (#18) without repeating it, since that one is about the audit process and this one is about the specific mistakes an audit tends to find.*

### 6. Pinterest Business Account Setup Checklist → Reframe as a literal, orderable checklist
**New angle:** This should be the most tactical, skimmable post in the set — a true checklist, distinct from the more explanatory "Profile SEO" and "How to Set Up a Pinterest Business Account Correctly" posts.
**New hook:** "Bookmark this one — it's meant to be worked through in order, not read once."
**New structure (checklist format, genuinely distinct presentation):**
☐ Business account converted or created
☐ Profile name states what you offer
☐ Bio written in plain, searchable language
☐ Website connected and verified
☐ 5-10 boards created around real business topics
☐ Each board titled and described with real search terms
☐ First 10-15 Pins published, each linked to a specific page
☐ Analytics reviewed after 30 days to confirm what's working

---

*Annotation:* Same fix logic as the first duplicate cluster — assign each post a genuinely distinct job (titles vs. descriptions, profile vs. boards vs. checklist) instead of five posts explaining the same setup process five times. The "Pinterest SEO Mistakes" post now functions as a self-diagnostic companion to the audit post rather than a sixth repeat of "here's how to set up an account."
